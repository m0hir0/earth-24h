# 地球の24時間

時計の 0:00 に地球が生まれ、24:00 が今。46億年の地球史を、今日の1日として流すウェブページです。時計は開いた端末の現地時間（日本なら日本時間）で動きます。日本語と英語に対応しています（ブラウザの言語で自動選択、画面右上で切り替え、`?lang=en` でも指定可）。

**公開ページ：https://earth24h.com/**

## できること

- **進化ガチャ（トップ）** — 46億年のどこかにランダムに生まれ（または「いまの地球時計の時代」に生まれ）、その生き物の系統として、分かれ道で進化を選びながら今日まで生き残れるかに挑みます。大量絶滅による淘汰があり、同じ瞬間に生まれた4つの系統も並んで進化します。結果は画像とリンクでSNSにシェアでき、リンクを開いた人にはその結果が表示されます。結末は全43種類（生き残り25・絶滅17・誕生前1）。生き残れば子孫の今日の暮らし、絶滅すればその化石が眠る地層が、結末ごとの専用カードになり、「結末の図鑑」に集まります。進化の途中でなった姿（全38種類）は「生き物の図鑑」に集まり、まだの姿は影で表示されます。生きた系統は履歴としても残ります（そのブラウザにだけ保存）。
- **いまの地球** — どの画面にいても、上部で24時間時計が動き続けています。現地時間の時刻が、そのまま地球の歴史の時刻です。今どの時代か、次に何が起きるかを、ドット絵の風景と、時代で姿が変わる回る地球と一緒に表示します。人類が現れるのは毎晩 23:59:54。
- **今を拡大** — 23:57からの最後の3分間を、時間をゆるめながら約3分で再生します。ゲージをドラッグして進めたり戻したりできます。最後の区間は、AIが台頭したこの十数年です。

前の版（46億年を1〜10分で流すタイプ）は [`v1/`](https://earth24h.com/v1/) にあります。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面とスタイル |
| `i18n.js` | 言語の選択と現地時間、翻訳の仕組み |
| `lang-en.js` | 英語の文章（日本語の文章をキーにした辞書） |
| `data.js` | 出来事・地質年代・AIの歩みなどのデータと、時刻や年数の書式 |
| `scenes.js` | 時代ごとのドット絵の風景（192×64 で描いて拡大） |
| `globe.js` | 「いまの地球」の時計の中心で回る、時代で姿が変わる地球 |
| `evo.js` | 進化ガチャの中身（生まれる生き物、分かれ道、大量絶滅、種の数の増減） |
| `app.js` | 画面の切り替えと動き |
| `og.png` | SNSで共有したときに表示される画像 |
| `v1/index.html` | 前の版（1ファイル） |

ビルドは不要です。手元で試すときは、このフォルダで次を実行して http://localhost:8124 を開きます。

```bash
python3 -m http.server 8124
```

## 注意

年代は国際年代層序表や研究で使われる代表的な推定値で、幅や諸説があります。酸素・1日の長さ・太陽の明るさは目安です。進化ガチャの淘汰は、実際の大量絶滅を手がかりにした、ゲームとしての単純化です。
