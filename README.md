# 地球の24時間

日本時間の 0:00 に地球が生まれ、24:00 が今。46億年の地球史を、今日の1日として流すウェブページです。

**公開ページ：https://m0hir0.github.io/earth-24h/**

## できること

- **いまの地球** — 日本時間の時刻が、そのまま地球の歴史の時刻になります。今どの時代か、次に何が起きるかを、ドット絵の風景と一緒に表示します。人類が現れるのは毎晩 23:59:54。
- **今を拡大** — 24:00 の直前を拡大して、人類の5.6秒と、AIの台頭（最後の約1ミリ秒）を詳しく見られます。
- **進化ガチャ** — 46億年のどこかにランダムに生まれ、その生き物の系統として、分かれ道で進化を選びながら今日まで生き残れるかに挑みます。大量絶滅による淘汰があり、同じ瞬間に生まれた4つの系統も並んで進化します。

前の版（46億年を1〜10分で流すタイプ）は [`v1/`](https://m0hir0.github.io/earth-24h/v1/) にあります。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面とスタイル |
| `data.js` | 出来事・地質年代・AIの歩みなどのデータと、時刻や年数の書式 |
| `scenes.js` | 時代ごとのドット絵の風景（192×64 で描いて拡大） |
| `evo.js` | 進化ガチャの中身（生まれる生き物、分かれ道、大量絶滅、種の数の増減） |
| `app.js` | 画面の切り替えと動き |
| `v1/index.html` | 前の版（1ファイル） |

ビルドは不要です。手元で試すときは、このフォルダで次を実行して http://localhost:8124 を開きます。

```bash
python3 -m http.server 8124
```

## 注意

年代は国際年代層序表や研究で使われる代表的な推定値で、幅や諸説があります。酸素・1日の長さ・太陽の明るさは目安です。進化ガチャの淘汰は、実際の大量絶滅を手がかりにした、ゲームとしての単純化です。
