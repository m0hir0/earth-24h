## 結論と修正

表示1000個の内訳は **仮想地球999個＋今の地球を示す◎1個**。もともと◎は抽選・集計から除外されていたが、途中と結果の分母、最終画面、X共有文、OG説明が「1000回」と書かれ、集計範囲が一致していなかった。

この構成と確率は維持し、表示を次のように統一した。

- 途中の生存数の分母は999。結果の内訳も999個で、◎の1個は別記する。
- ◎は「人類が現れた現実を示す印」。仮の確率で当選した標本ではない。
- 0個の場合は「999個の仮想地球では、わたしたちのような人類は現れませんでした」。現実の地球を含めた不在宣言にしない。
- 結果・共有文・OG説明にも仮の条件であることを含め、真の発生確率や個人の誕生確率の推定と混同させない。
- 関門の順序、別の星の姿も単純化した仮定と明記。史実の因果関係や唯一の必須経路を検証したモデルではない。
- 終了時の仮想地球の通過個体と◎を、人類を示す色にそろえる。前は通過個体が青のままで、凡例の金色と異なっていた。
- 再実行時に結果数・状態・光の演出を初期化。日英両方を修正。

「この星の歴史から、今のあなたにつなぐ」という演出と祖先の場面は維持した。成功例を増やすための確率調整はしていない。

## 確率の検算

各値は科学的な確率ではなく、現行コードの仮の通過率である。

```text
p = 0.7 × 0.5 × 0.1 × 0.7 × 0.5 × 0.4 × 0.3 × 0.15 × 0.1 × 0.3
  = 0.000006615（割合）= 0.0006615%
```

前の関門まで通過した個体だけが次へ進むため、各pは「そこまで進んだ条件下の次の通過率」として扱う。積を取るために実際の地球史の各出来事が互いに独立だと仮定する必要はない。一方、999個の仮想地球どうしは独立試行として実装されている。

人類が現れた仮想地球の個数Kは、このモデル内で二項分布 `Binomial(999, p)`。

- 平均：`999p = 0.006608385個 / 回`
- 0個：`(1-p)^999 = 99.3413380643%`
- 1個以上：`1-(1-p)^999 = 0.6586619357%`
- 少なくとも1個現れる実行までの平均待ち回数：約151.8回

◎を加えた画面上の人類の星の個数は `K+1`。それを1000で割った値は、固定された◎を含むため発生確率の推定には使えない。「現実に人類がいる」という観測事実も、それだけで仮の各pを正当化したり、真の確率を定めたりはしない。

また、`others` の「別の人類」と `humans` の「わたしたちのような人類」は元の別カテゴリを維持している。ここでいうKは後者（全10関門通過）のみ。結果画面には両者の凡例を残し、見出しと共有文も「わたしたちのような人類」に限定した。「別の人類」がいるのに人類全体が0だと読める文章を避けている。

## 架空データによる反復検証

`distribution.cjs` は画面と同じ `passGate()` と `tally()` をVMから読み込み、各実行で状態を新しくして全10関門を通す。固定シード20261026、Mulberry32、100,000回、各999個。実際の地球史の観測データではない。

| 人類が現れた仮想地球 | 回数 | 架空試行の割合 | 理論割合 |
|---|---:|---:|---:|
| 0個 | 99,312 | 99.312% | 99.341338% |
| 1個 | 684 | 0.684% | 0.656490% |
| 2個 | 3 | 0.003% | 0.002167% |
| 3個以上 | 1 | 0.001% | 0.000004772% |

人類が現れた総数693個、平均0.00693個 / 回。◎は全実行で抽選されず、集計合計は毎回999個と確認した。全関門の生存数の平均も理論値と照合し、6標準偏差の許容範囲内。

3個以上は理論期待件数が約0.0048回にすぎず、今回の1回は希少な結果。裾の各小区分が理論に収束したとは扱わない。分布チェックでは希少区分を「2個以上」にまとめて比較する（合計4回、理論期待約2.17回）。この単一シードの一致は実装点検の補助であり、乱数品質やモデルの科学的妥当性の証明ではない。

数値の全出力：`distribution-20261026.json`。
